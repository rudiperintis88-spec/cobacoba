Gabungan sheet Gatsu, Gagak Hitam, dan Flamboyan. Hanya baris dengan Leasing = Cash.

Tabel di bawah masih berisi data contoh. Halaman mencoba mengambil data dari Google Sheets saat dibuka. Kalau gagal, buka file ini langsung di browser atau unggah CSV tiap sheet cabang dengan tombol Unggah CSV.
Cara mengambil CSV dari Google Sheets
  1. Buka file Google Sheets, pilih tab Gatsu.
  2. Klik File, Download, Comma Separated Values (.csv).
  3. Ulangi untuk tab Gagak Hitam dan Flamboyan.
  4. Klik Unggah CSV di halaman ini, lalu pilih ketiga file sekaligus.
